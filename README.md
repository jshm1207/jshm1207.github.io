## 구성
- `index.html` — 청첩장 페이지 전체 (디자인, 효과, 계좌 복사, 갤러리)
- `photos/` — 메인 사진(`main.jpg`), 갤러리 사진(`p01`–`p22`), 링크 미리보기 사진(`og.jpg`)
- `music/bgm.mp3` — 배경음악 (신랑신부가 고른 곡, 약 1분 반복)
- `.nojekyll` — GitHub Pages가 파일을 그대로 보여주도록 하는 빈 파일

## GitHub Pages로 공개하기
1. GitHub에서 새 저장소를 만듭니다 (예: `wedding`). 무료 계정은 **Public** 이어야 Pages를 쓸 수 있어요.
2. 이 폴더 안의 파일과 `photos` 폴더를 전부 올립니다 (Add file → Upload files).
3. Settings → Pages → Branch를 `main` / `(root)` 로 선택하고 Save.
4. 1~2분 뒤 `https://jshm1207.github.io/` 주소로 열립니다.

## 카카오톡 미리보기 사진
주소가 정해지면 `index.html`의 `og:image` 값을 전체 주소로 바꿔주세요.
예: `https://jshm1207.github.io/photos/og.jpg`
